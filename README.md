# ⚽ SOCCER POOL 5vs5

駒をはじいてゴールを狙う、ターン制のサッカーゲームです。ブラウザだけで動きます（スマホ縦画面向け）。

## 遊び方
1. 自分の駒をタップして選びます。
2. 画面のどこでもよいので、引っ張って離します。引いた向きと反対の方向に発射され、引いた距離がパワーになります。
3. **スピン（テクニック）**：画面下で曲げる方向（↶ 左 / ・ なし / ↷ 右）を選びます。
   - 引っ張っている間、ゲージが 0→100%→0 と往復します（1往復1.3秒）。**離した瞬間のゲージの値**が曲がり具合になります。
   - 右端の斜線ゾーン（92%以上）で離すと最大カーブです。予測線もゲージに合わせて動きます。
   - 打つと方向は「なし」に戻ります。回転はぶつかった相手（ボールなど）にも一部伝わります。
- **ゴール前ルール**：斜線のゴールエリア（ボックス内の一番内側、GK ONLY）には、ゴールキーパー以外の駒は入れません（両チームとも）。ボールは自由に出入りできます。
- 全部の駒が止まると相手の番になります。先に3点取った方の勝ちです。

## 画面の流れ
タイトル（名前・アイコン設定）▶ モード選択（CPU対戦／2人対戦／オンライン／フォーメーション設定）▶ 詳細設定（強さ・フォーメーションなど）▶ 試合

## モード
| モード | 内容 |
|---|---|
| CPU対戦 | 強さは「弱い・普通・強い・最強」の4段階（最強は相手の返しまで読みます） |
| 2人対戦 | 1台の端末を交互に使って対戦 |
| オンライン | 部屋コードを共有して、別々の端末で対戦（P2P通信） |
| フォーメーション設定 | 自分の配置を作って保存（どのモードでも呼び出せます） |

試合の前に、フォーメーション（2-2 / 1-2-1 / 3-1 / 1-3 / 2-1-1 / 4-0）を選べます。駒をドラッグして自由に配置することもできます。

## カスタマイズ
- **プレイヤー名**：メニューで名前（10文字まで）を入れると、スコアボードや手番表示に出ます。2人対戦では1P・2Pそれぞれ設定できます。
- **駒のアイコン**：名前の左の丸をタップして画像を選ぶと、自分の駒の中央がその画像になります（外枠はチームカラー、GKは金）。↺で元に戻せます。オンライン対戦では相手の画面にも表示されます。
- **マイフォーメーション**：フォーメーション画面で配置に名前をつけて「保存」すると、★付きのボタンとして呼び出せます（12件まで）。×を2回タップで削除。
- 設定はブラウザ内（localStorage）に保存されます。

## ファイル構成
```
index.html        ゲーム本体（HTML / CSS / JavaScript を1ファイルにまとめています）
assets/           画像素材（駒・ボール・芝・木目・ネット・背景・ロゴ）
```

## 技術メモ
- **描画**：Canvas 2D を使っています。
- **効果音**：Web Audio API で合成しているので、音声ファイルはありません。
- **物理演算**：60fps の固定ステップで計算し、1ステップを4回に分けて当たり判定しています。
- **スピン**：毎ステップ、速度ベクトルを少しずつ回転させて曲げています（マグヌス効果風）。三角関数を使わず四則演算と平方根だけで計算しているので、端末が違っても結果が完全に一致します。
- **CPU**：打ち方の候補ごとに結果をシミュレーションし、一番よい一手を選びます。
- **オンライン**：[PeerJS](https://peerjs.com/)（WebRTC）で端末どうしを直接つなぎます。打つたびに「打つ直前の全部の駒の座標」と「速度ベクトル」を送ります。受け取った側は同じ物理計算をし直すので、結果が両方の端末で一致します。
  - 接続の仲介には PeerJS の無料公開サーバーを使っています。
  - 回線によっては（一部のモバイル回線や社内ネットワークなど）つながらないことがあります。

## ローカルで動かす
`index.html` をブラウザで開くだけで遊べます。オンライン対戦を試す場合は、ローカルサーバーで開いてください（例：`python -m http.server`）。
